# PyPTO-X 交接档案

交接性质的文档统一使用：

```text
NNNN-YYYY-MM-DD-<阶段或主题>.zh-CN.md
```

- `NNNN` 是四位递增序号，只表示归档顺序；
- 日期使用 Asia/Shanghai 的自然日；
- 根目录 `HANDOFF.zh-CN.md` 始终保存最新的滚动接手信息；
- 本目录保存阶段快照，历史文件只追加勘误，不覆盖原结论。
